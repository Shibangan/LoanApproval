## 💳 AI Financial Risk & Credit Scoring Platform

> An end-to-end credit-risk ML platform that predicts default risk, maps probability to an interpretable score, explains predictions, and deploys the workflow through an interactive dashboard.

**Stack:** Python · Pandas · NumPy · Scikit-learn · SHAP · Streamlit · Docker

### Workflow

```text
Applicant Data → Validation → Feature Engineering → ML Model
       ↓
Probability of Default → Credit Score → Risk Band → Explanation
       ↓
Streamlit Dashboard / Docker Deployment
```
