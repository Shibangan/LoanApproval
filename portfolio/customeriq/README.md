# 🛒 CustomerIQ

Customer segmentation project using transaction behaviour to identify valuable, loyal and at-risk customer groups.

### Workflow
`Transaction Data → RFM Features → Scaling → K-Means → Segment Profiling → Business Actions`

### Analysis
- Recency
- Frequency
- Monetary value
- Cluster profiles
- Customer lifetime patterns

### Portfolio goals
Build an interactive dashboard showing segment size, revenue contribution and recommended actions for each cluster.
