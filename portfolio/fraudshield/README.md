# 💳 FraudShield

A machine-learning project for detecting suspicious financial transactions while focusing on the metrics that matter for highly imbalanced classification.

### Workflow
`Data Validation → Class Imbalance Analysis → Feature Engineering → Model Training → Threshold Tuning → Evaluation`

### Key metrics
Precision · Recall · F1 · PR-AUC · ROC-AUC · Confusion Matrix

### Portfolio goals
- Establish a simple baseline
- Compare tree-based classifiers
- Tune the decision threshold
- Explain false positives and false negatives
- Add a lightweight monitoring dashboard

> Use an appropriate public or synthetic dataset and document the data source before publishing results.
