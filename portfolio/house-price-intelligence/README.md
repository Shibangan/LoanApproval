# 🏠 House Price Intelligence

A regression project that studies which property characteristics influence price and builds a prediction workflow.

### Workflow
`Data Cleaning → EDA → Feature Engineering → Regression → Evaluation → Explainability`

### Suggested stack
Python · Pandas · NumPy · Scikit-learn · Matplotlib · Seaborn · SHAP

### Portfolio goals
- Compare Linear Regression, Random Forest and Gradient Boosting
- Evaluate MAE, RMSE and R²
- Analyse feature importance
- Finish with a Streamlit prediction interface

> Dataset and model outputs should be added once the project is implemented and validated.
