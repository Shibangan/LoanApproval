# 📈 Demand Forecasting

A time-series project for forecasting future product demand and identifying seasonal patterns.

### Workflow
`Date Validation → Aggregation → Trend/Seasonality → Baseline → Forecast Model → Backtesting → Visualization`

### Models to explore
- Seasonal Naive baseline
- Exponential Smoothing
- ARIMA/SARIMA
- Gradient boosting with lag features

### Evaluation
MAE · RMSE · MAPE, with time-aware backtesting rather than random train/test splitting.

### Portfolio goals
Finish with a forecast dashboard showing historical demand, forecast intervals and business-oriented inventory recommendations.
