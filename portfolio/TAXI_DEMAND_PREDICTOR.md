# 🚕 Taxi Demand Predictor

A geospatial and time-series project for analyzing taxi demand by location and time, identifying peak-demand zones, and forecasting future demand.

**Focus:** Time Series · Geospatial Analysis · Feature Engineering · Forecasting · Visualization

**Planned stack:** Python · Pandas · NumPy · Scikit-learn · Matplotlib · Plotly

**Roadmap:** trip cleaning → temporal features → location aggregation → demand heatmaps → lag features → forecast model → error analysis → interactive map.
