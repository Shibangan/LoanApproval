# 🛒 CustomerIQ

A customer analytics project using RFM-style behavioral features and clustering to identify meaningful customer segments.

**Focus:** Customer Analytics · RFM · K-Means · Clustering · Business Insights

**Planned stack:** Python · Pandas · NumPy · Scikit-learn · Matplotlib · Seaborn · Streamlit

**Roadmap:** transaction cleaning → customer-level features → RFM scoring → segment discovery → cluster evaluation → visualization → business recommendations.
