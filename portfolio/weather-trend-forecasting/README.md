# 🌦️ Weather Trend & Forecasting

A practical data science project for exploring historical weather patterns, identifying seasonal trends, and forecasting future temperature using time-series methods.

## 🎯 Objectives

- Clean and analyze historical weather data
- Explore daily, monthly, and seasonal temperature trends
- Visualize temperature, rainfall, and humidity patterns
- Create lag and rolling-window features
- Build and evaluate a baseline forecasting model
- Compare predicted values with actual observations

## 🧰 Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## 📊 Workflow

1. Data collection and validation
2. Date/time preprocessing
3. Exploratory data analysis
4. Seasonal and trend analysis
5. Feature engineering
6. Forecasting model development
7. Model evaluation
8. Visualization of forecast results
