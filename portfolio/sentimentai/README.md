# 💬 SentimentAI

An NLP classification project that turns customer text into actionable sentiment signals.

### Workflow
`Text Cleaning → Tokenization → TF-IDF → Classification → Error Analysis → Prediction UI`

### Models to compare
- Logistic Regression
- Linear SVM
- Naive Bayes
- Optional transformer baseline

### Evaluation
Accuracy · Precision · Recall · F1 · Confusion Matrix

### Portfolio goals
Include examples of correctly classified text, difficult edge cases and a small Streamlit interface for live predictions.
