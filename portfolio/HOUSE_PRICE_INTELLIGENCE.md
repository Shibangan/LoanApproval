# 🏠 House Price Intelligence

A regression-focused project for analyzing housing data, discovering the drivers of property value, and building a transparent house-price prediction workflow.

**Focus:** EDA · Feature Engineering · Regression · Explainability · Visualization

**Planned stack:** Python · Pandas · NumPy · Scikit-learn · Matplotlib · Seaborn · Streamlit

**Roadmap:** data cleaning → exploratory analysis → feature engineering → baseline regression → model comparison → explainability → interactive dashboard.
